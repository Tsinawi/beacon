What it does

What leadership gets

One calendar for every community

See, edit and approve a month of posts for any property, or all of them, in one place.

Content that stays accurate

Captions use only what each community's website says. If a fact is missing, the post is flagged instead of guessed.

Fair housing built in

Every caption is checked before approval, and every branded image carries the Equal Housing Opportunity line.

On-brand images automatically

Real property photos get the community logo, amenity icons and four rotating Beacon layouts. Floor plan flyers post clean.

Fast one-off posts

Upload a finished graphic, such as a new phone number, and Claude writes the caption from what's in the image.

Safe, controlled publishing

A dedicated Meta account with posting-only access. Posts that change after approval are blocked, and publishing can be paused with one click.

How I built it

My ideas, brought to life with Claude Code

The biggest help was the coding. I knew what our communities needed; Claude Code turned those ideas into working software.

I described what I wanted in plain language, the way I would brief an agency, and Claude Code wrote, tested and published the code. I reviewed each version and asked for changes until it worked the way our team does.

  • I set the direction: which platforms, the posting cadence and content mix, the approval rules, the brand look, and what to fix when a draft wasn't right.
  • Claude Code did the building: the calendar and editor, the website reader, the branded image designer, the content checks and the automatic publisher.
  • Security came first: Meta access runs through a dedicated account that can only create content on the pilot Pages. Its key is held in a secure credential store, never in the code or in chat.
  • Time: about four weeks from first idea to fully automatic posting.
