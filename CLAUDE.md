# Beacon Social

Social media planning for Beacon Management's apartment communities. See README.md for the architecture and data model.

- The command center is `app/command-center.html`, published as https://claude.ai/artifact/G626QaLTCbynVtY1WMb7wj. Republish it from that file after changes.
- Each community's website is the source of truth. Never invent amenities, floor plans, prices or specials.
- Fair housing: posts describe the property, never who should live there.
- The monthly website refresh and drafting run follows `ops/monthly-run.md`.
